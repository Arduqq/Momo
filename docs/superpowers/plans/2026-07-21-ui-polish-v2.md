# Momo UI Polish v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix five UI regressions/improvements in Canvas.tsx: restore tldraw pages panel, relocate style panel, add gradients + themes, extend zoom + stroke weight, auto-close detail panel.

**Architecture:** All changes are in `src/components/Canvas.tsx`. No new files, no new IPC handlers. The spec is at `docs/superpowers/specs/2026-07-21-ui-polish-v2-design.md` — read it for full context and rationale.

**Tech Stack:** React 19, TypeScript, tldraw 4.5.9, Electron 41, electron-store via IPC

## Global Constraints

- tldraw version: 4.5.9 — do not upgrade
- No new IPC handlers — reuse existing `get-store-value` / `set-store-value` and workspace background IPC
- Store keys: `'global-dark-mode'` (boolean, default `true`), `'global-stroke-extra'` (number, default `0`)
- CSS custom property for font: `--momo-font` on `document.documentElement` (already set by v0.0.6 code)
- TypeScript must pass `npx tsc -p tsconfig.app.json --noEmit` with no errors after each task
- `BackgroundConfig.gradient` field: empty string `''` when unused (never undefined/null)
